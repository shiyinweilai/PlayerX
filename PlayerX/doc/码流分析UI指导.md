# 码流分析模块 UI 设计指导（参考建议 · v2）

> 本文档是对 `码流分析架构.md` 的 UI 层补充说明。相比 v1，本版明确了核心背景：**画面显示以解码后的 YUV 帧为准，CU 划分逐帧叠加在该画面上，QP 作为可切换的着色叠加层，块级详细信息仅在用户点击某个 CU 时才弹出**，而不是做成独立于视频画面的抽象统计视图。核心原则不变：优先复用 `主题.md` 与 YUV 分析面板（`YuvWindow.qml`/`YuvStatsPanel.qml`）已验证的组件与配色。

---

## 0. 核心背景（本版新增，决定整体布局）

1. **主显示区就是解码画面本身**：直接复用 `YuvDisplayItem` 的渲染管线（物理像素级渲染、滚轮缩放、拖拽平移），码流分析不是另开一个"示意图"视图，而是在已有的 YUV 画面上叠加信息层。
2. **CU 划分是常驻叠加层**：只要当前帧的块级信息（`RBBlockInfo`）可用，网格线默认绘制在画面上，随播放逐帧刷新，随画面缩放/平移同步变换（网格必须跟手，不能错位）。
3. **QP 是可切换叠加层，不是常驻的**：通过一个开关控制是否在 CU 网格内叠加 QP 着色/数值，关闭时只看网格线，避免默认就很花。
4. **块信息是点击触发的，不是悬停/常驻的**：鼠标悬停只做 CU 边框高亮提示（低成本），点击才弹出该块的详细数值卡片，和现有 YUV 像素点击取值的交互模型完全一致，直接复用。

---

## 1. 整体布局（从上到下 / 从左到右）

```
┌─────────────────────────────────────────────┬───────────────┐
│  顶部：流信息条（分辨率/帧率/编码/Profile-Level）│               │
├─────────────────────────────────────────────┤   右侧：数值    │
│                                               │   统计卡片      │
│         主显示区：解码YUV画面                  │   （复用        │
│         + CU网格叠加层（常驻）                 │   PlaneGradient │
│         + QP着色叠加层（可切换）                │   Card 表格样式）│
│         + 点击CU弹出详情卡片                    │               │
│                                               │               │
├─────────────────────────────────────────────┴───────────────┤
│  底部：帧时间轴/GOP色块条 + 帧号文本（复用 YUV 底部控制条模式）  │
└───────────────────────────────────────────────────────────────┘
```

这个结构直接对应 `YuvWindow.qml` 现有的"主画面 + 右侧统计面板 + 底部控制条"三段式布局，**不新增窗体分区**，只是把右侧面板内容换成码流统计、底部条换成帧类型时间轴。

## 2. 配色与视觉语言（直接复用现有 token）

### 背景层级
- 外层容器 `#101012` → 卡片 `#1a1a22` / `#121417` → 卡片内表格底 `#1a1d22`

### 描边与圆角
- 描边统一 `#2a2e33`，1px；圆角：小控件 `radius: 3`，卡片 `radius: 4~6`

### 文字层级（三级灰阶）
- 主数值：`#cccccc`；次要标签：`#9aa0a6`；弱提示：`#6a6f76`
- **数值类必须使用 `font.family: "Monospace"`**（QP/坐标/MV 数字表格对齐是刚需）

### 语义色映射
| 语义 | 颜色 |
|---|---|
| I/IDR 帧、关键帧标记 | `#f0c040`（黄） |
| P 帧 | `#3a6fd8`（蓝） |
| B 帧 | `#6a6f76`（中性灰） |
| GOP 边界 | 1px 黄色竖线 |
| CU 网格线 | 半透明白 `rgba(255,255,255,0.35)`，1px，不抢画面 |
| 选中/悬停 CU 边框 | `#f0c040`，1.5px，高亮但不遮挡内容 |
| QP 着色（低→高） | 冷蓝 → 中性灰 → 暖红（**不用绿色**） |

## 3. 主显示区：CU 网格叠加层（常驻）

- 复用 `YuvDisplayItem` 已有的缩放/平移状态（`globalScale`/`panX`/`panY`），网格绘制必须用同一套坐标变换，保证跟随画面缩放平移不错位。
- 网格线本身极简：半透明白色细线，仅勾出 CU 边界，不填充、不加文字（文字/着色属于下面的 QP 叠加层，避免网格层信息过载）。
- 数据来源为 `RBStreamAnalyzer::rbBlockInfoAt(frameIndex)`；若当前格式/文件没有块级数据（未走 §4 补丁路径），整层不绘制，同时在右侧统计卡片区域给一行灰色小字提示"当前格式不支持块级分析"，不用弹窗打断。

## 4. 主显示区：QP 着色叠加层（可切换开关）

- 在顶部流信息条或右侧面板顶部放一个小开关（复用现有按钮样式，参照内嵌控制按钮的显示/隐藏交互），文案"显示QP"，默认关闭。
- 打开后，每个 CU 网格内部叠加半透明色块（冷蓝→中性灰→暖红），透明度建议 40%~55%，保证底层 YUV 画面内容仍可辨认，不是完全覆盖。
- 当画面缩放到足够大（单个 CU 在屏幕上 ≥ 某阈值，如 40px）时，可在色块中心叠加小号等宽字体 QP 数值文本（灰底黑字或直接用主文字色 `#cccccc`），避免小尺寸下文字堆叠成一团。

## 5. 点击 CU 弹出详情卡片（唯一的块信息展示方式）

- 悬停：仅做当前 CU 边框高亮（`#f0c040` 描边），不弹任何内容，成本要低。
- 点击：弹出一张小卡片，位置跟随点击点（复用 YUV 像素点击取值弹窗的定位逻辑），内容采用 `PlaneGradientCard` 的"表头+数值行"表格样式：

```
┌──────────────────────────┐
│ CU  x:120 y:64  16×16      │
├──────────────────────────┤
│ QP    类型     MV          │
│ 28    Inter   (+3,-1)      │
└──────────────────────────┘
```

- 卡片背景/描边照抄 `主题.md` 弹层规范（`#cc1a1a1f` 半透明深色背景），再次点击画面空白处或按 Esc 关闭，不需要常驻。

---

## 6. 底部：帧时间轴 / GOP 视图

- 帧色块行高 18~22px，横向 `Flickable` 滚动，顶部叠加缩略概览 minimap 条（按像素桶聚合平均码率/帧类型），避免长视频卡顿。
- 悬停用小 tooltip 显示帧号/类型/QP均值/大小，点击直接 seek 播放位置到该帧（复用 `seekPlayerTo`）。
- 帧号文本仍放最右/最下角，风格对齐 YUV 底部纯数字帧号（无进度条）。

## 7. 右侧：数值统计卡片

- 直接复用 `PlaneGradientCard` 的表头合并均值列的表格布局，展示当前帧整体的 QP 均值/极差、码率、帧类型、POC 等，不需要新设计。
- 码率曲线（折线图，`#42A5FF`，1.5px）可放在统计卡片下方，HRD 越限区间用半透明暗红 `#301a1a` 背景块提示，不弹窗。

---

## 8. 交互一致性

- 快捷键复用 `GlobalShortcuts.qml` 按 `currentTab` 分发（左右帧进退、上下快进快退、空格播放暂停），码流分析 tab 下追加：点击画面=查看CU详情，Esc/空白处点击=关闭详情卡片。
- 缩放/平移交互（滚轮缩放、Ctrl+R 重置）直接复用 YUV 窗口现成实现，CU 网格与 QP 叠加层随之同步变换即可，不单独做一套缩放逻辑。

---

## 9. 组件复用对照表

| 新需求 | 直接复用的现有组件/模式 |
|---|---|
| 主画面渲染+缩放平移 | `YuvDisplayItem`（原样复用，仅新增叠加层绘制） |
| CU/QP 叠加层坐标变换 | 复用 `globalScale`/`panX`/`panY` 状态 |
| 点击弹出块详情卡片 | YUV 像素点击取值弹窗的定位与样式 |
| 详情卡片表格样式 | `PlaneGradientCard`（表头+数值行） |
| 弹层/Popup 规范 | `主题.md` 自绘 Popup |
| 快捷键分发 | `GlobalShortcuts.qml` 按 `currentTab` 分发 |
| 帧进度显示 | YUV 底部纯数字帧号（无进度条） |
| 直方图/曲线绘制 | YUV 直方图 Canvas 绘制方式 |

---

## 10. 唯二真正需要新设计的部分

1. **CU 网格 + QP 着色叠加层**：绘制在现有 YUV 画面上，跟随缩放平移，QP 可开关
2. **点击 CU 详情卡片 + 底部帧时间轴/GOP 视图**：交互模型复用现有点击取值/底部控制条，只是内容变成块级语法信息

除此之外的所有配色、组件、快捷键、缩放平移均直接复用现有 YUV 分析实现。
