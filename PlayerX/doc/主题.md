
【PlayerX QML 弹层强制规范 · 必须严格遵守】

1. 禁止使用 QtQuick.Controls 的 Menu 做自定义样式下拉。
   原因：macOS 上 Menu 会被 Qt 替换为原生 NSMenu，
   自定义 background / delegate / contentItem 全部失效，
   会漏出系统白底黑字。
   一律改用 Popup + ListView（或 Repeater）自绘。
   Menu 只允许出现在 macOS 全局菜单栏（MenuBar）。
2. 禁止任何弹层 / 菜单 / 提示出现白底。
   全项目弹层配色统一对齐 Main.qml 全局 ToolTip 主题：

   - 背景         #cc1a1a1f   （半透明深色，伪毛玻璃）
   - 描边         #33ffffff   1px
   - 圆角         6
   - 文字         #e8e8ec     （锁死，禁止黑/灰）
   - 字号         13
   - 行高         28
   - padding      6
   - 弹层与按钮间隙 2px
   - 悬停高亮     整行蓝底 #0a64f0，文字仍 #e8e8ec
     禁止用 #33333a 等灰色（看起来像禁用）
   - ✓ 勾选标记   白色 #e8e8ec（不要用蓝色，蓝色留给 hover）
   - 分隔线       1px #33ffffff
3. Popup 弹出位置统一用：
   openAt(anchorBtn) {
   var p = anchorBtn.mapToItem(parent, 0, 0)
   x = p.x
   y = p.y - implicitHeight - 2   // 向上弹；向下弹改成 + anchorBtn.height + 2
   open()
   }
   ListView 必须 interactive: false。
   行内交互用 HoverHandler + TapHandler，不要 MouseArea 嵌套。
4. 参考实现：Main.qml 中的 phoneAspectPopup。
   新增任何弹层前先看它，照抄结构和配色。
5. 改动检查清单（每次写完弹层都自检一遍）：
   □ 用的是 Popup，不是 Menu
   □ 背景 #cc1a1a1f，不是任何浅色
   □ 文字 #e8e8ec，不是黑/灰
   □ Hover 是蓝色 #0a64f0，不是灰色
   □ 没有遗留 Menu / MenuItem / MenuSeparator
   □ macOS 实机看一眼，没有白底漏出

违反以上任意一条 = 错误实现，必须返工。
