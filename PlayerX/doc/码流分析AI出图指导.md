# 码流分析模块 · AI 出图指导（精简版）

> 用途：作为 AI 图像生成的提示词参考，融合架构与 UI 两份文档核心要点，控制在 1000 字以内。

## 场景
生成一张 PlayerX 播放器"码流分析"功能的深色主题 UI 设计稿/概念图，风格与视频/YUV分析面板保持一致，专业、克制、数据密度高但不杂乱。

## 整体风格
暗色专业视频工具界面，类似 Adobe/DaVinci Resolve 调色台风格。背景近黑色 #101012，卡片面板 #1a1a22，卡片内表格底色 #1a1d22，1px 描边 #2a2e33，圆角 4-6px。全局无阴影、无渐变高光，纯扁平深色卡片堆叠。

## 文字与数值
文字三级灰阶：主数值浅灰 #cccccc，次要标签中灰 #9aa0a6，弱提示深灰 #6a6f76。所有数字（帧号、QP值、码率、时间码）使用等宽字体，等宽对齐排列成表格，禁止比例字体导致数字抖动错位。

## 语义强调色
关键帧(I/IDR)：暖黄色 #f0c040 色块标记；
P帧：蓝色 #3a6fd8 色块；
B帧：中性灰 #6a6f76 色块；
GOP分界线：细黄色竖线；
码率越限告警区域：半透明暗红色叠加块 #301a1a，不用弹窗，仅背景提示。

## 布局结构（从上到下）
1. 顶部：流信息条——分辨率/帧率/编码格式/Profile-Level 等关键参数横向排列的紧凑文字条
2. 中部左：帧时间轴/GOP视图——细长色块序列(每帧18-22px高)横向排布，顶部叠加一条缩略概览mini-map条，代表整体码率/帧类型分布
3. 中部右：数值统计卡片——表头+数值行的网格化小卡片（类似均值/标准差/极差/方差四列一行的紧凑表格）
4. 下部：码率曲线图——细折线图(线宽约1.5px，蓝色#42A5FF)，横轴为帧序号，曲线下方可叠加半透明红色告警区块
5. 可选悬浮层：QP热力图缩略图，色块从冷蓝（低QP高质量）过渡到暖红（高QP低质量），中间过渡用中性灰而非绿色

## 交互细节提示（画面中可体现）
悬浮气泡提示框使用深色半透明背景(#cc1a1a1f)、白色文字、细白边框，非系统默认白底提示样式；
多路码流并排对比槻位，每个槻位右上角带小号圆形关闭按钮(红色×图标)；
整体信息密度高但通过网格对齐和统一间距保持整洁，不使用鲜艳饱和色块，仅关键语义色(黄/蓝/红)做提示。

## 禁止项
不要白色/浅色背景；不要圆润拟物化风格；不要卡通化图标；不要彩虹渐变或强烈光效；不要不对齐的随意布局；不要使用绿色作为热力图或状态提示色。

## 一句话核心意象
"深色专业调色台风格的码流分析仪表盘：左侧帧类型时间轴+GOP色块，右侧统计数值网格卡片，底部蓝色码率曲线，黑底黄蓝灰三色语义标记，等宽数字整齐排列。"
